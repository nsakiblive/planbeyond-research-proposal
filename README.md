# Research and project support for PlanBeyond

A standalone introduction by Nazmus Sakib, prepared for Laura Troyani and the PlanBeyond team. This project is separate from the main portfolio and the UP THERE, EVERYWHERE proposal.

The page covers research and competitor intelligence, data mining and scraping, analysis, writing, project coordination, climate research and banking/institutional practice. It uses original photographs and project evidence from the public portfolio. Professional experience is distinguished from independent consulting.

## Website files

The static website is in `dist/`: HTML, CSS, JavaScript, five original images, a monogram SVG and a robots file. There is no build dependency, tracking, form, account or database. Images can be opened in a keyboard-accessible dialog. The menu supports mobile widths. Contact buttons open the visitor's email application.

`noindex` and robots exclusion express a search-indexing preference; they do not restrict access.
